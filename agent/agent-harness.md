# Agent 协作治理

闸门已经装在提交那一刻：只拦这一笔新引入的错误，存量放行，嫌疑与目录级体裁要求归人判。

体检报告也接上了：一次看完整仓，每期只说一处，用日常话讲清改哪里、怎么改。

接下来要回答的是闸门拦得准不准。答案只能从存量里数：把历史写入按今天的规则重判一遍，看有多少问题当年漏过去，又有多少是机器判错。巡检给闸门与报告一个基线，也给规则一条删改的路。

## 巡检

把历史写入按今天的规则重判一遍，数出「进库时就有问题、后来靠人改掉」的量。这个数回答的是：没有闸门的时候，漏过去多少。

- 逐次重判存量，按层级与时间两个方向分开数
- 真问题与提及分开计，误报单独一栏
- 抽一批人工复核，确认机器数可信

做完的样子：能一句话说出漏过去的量，以及其中被人工发现的比例；抽检任一条，陌生人当场可判。
