# quanttide-roadmap-of-founder

量潮创始人路线图 — 愿景、选择与待定方向。

## 概述

本仓库收录量潮创始人的愿景、选择与待定方向，按记忆集分目录、按主题分文件。当前收录：

- [work/](./work/)：工作主线的方向层。
  - [clarify-intent.md](./work/clarify-intent.md)：澄清意图（目标、核心问题、已/待决策，含 skill 流程）；命令行与字段见 quanttide-founder-lab 的 `docs/dev-guide/clarify-intent.md`。

## 格式

主题文件章节按序出现，空节省略：目标（含元目标子层）→ 核心问题 → 已决策 → 待决策。条目一行一条，已决策须有行动佐证，待决策须写清卡在哪。
