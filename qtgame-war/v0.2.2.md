# v0.2.2 — 认知与敌军指挥官

**目标**：认知管线与敌军决策落地，双方在信息不全的条件下完成一局，判断可追溯——对局从「可复算」变成「可对弈」。

**依赖**：v0.2.1。

## 架构决定

- **指挥部包与类型隔离**：新建 `packages/command`，纯 Dart，只依赖引擎公开的报告类型与参数表。lint 升格为硬检查：指挥部源码出现事件类型即编译失败——迷雾从类型层焊死。指挥部是主产品，引擎做哑。
- **认知四步**：过滤、延迟、失真、信念重算，各自纯函数，参数进参数表；帝丘店规则作为第一个参数化实例。
- **敌军对称**：敌军指挥官读自己的信念与性格参数出命令，走同一套翻译与契约；真相不进它的决策记录。
- **大模型不进结算**：只碰文本层。

## 待做

- [ ] 指挥部包 + 关卡翻译函数迁入 + 类型隔离 lint
- [ ] 过滤 / 延迟 / 失真三道纯函数，设计稿情报时间线作为手写期望

- [ ] `decide(turn, beliefs, rng) → decision` 决断：候选打分后择一，权重与候选集全进参数表；每次输出由主循环写入决策卷。**全路线图最不确定的一段**，对策是性质断言先行：置信度低时不大举进攻、打分与最终选择一致即达标，「打得好不好」留给人工对局
- [ ] 参谋翻译两级展开：战役级命令 → 部队任务 → 合法性预检；预检失败生成事件回传
- [ ] 双 AI 对弈无人值守模式（与人机对弈共用相位表）+ `sweep` 参数扫描最小版
- [ ] 迷雾断言：报告与真相比对，不在场事件不可见、迟到报告符合通信排程、假情报影响信念方向；对称性审查

## 验收

- 指挥部包零事件引用（CI）
- 双 AI 对弈跑完一局，五卷齐备
- 决断的性质断言全部通过；敌军每个决策能回答当时信了什么
- 同种子批量双跑，diff 零偏离
- 一次参数扫描（失真率五值乘十种子）产出曲线
- 故意注入的三处泄露都能被抓住

## 风险与未达标处理

- 决断「感觉不对」无客观标准 → 性质断言通过即算达标
- 行为失衡（某方必胜）→ 先调参数边界不改代码，陡峭区记入 v0.3.0
- 决断验收不过即冻结 v0.3.0：决策不可解释，人类入口接上也没有意义
